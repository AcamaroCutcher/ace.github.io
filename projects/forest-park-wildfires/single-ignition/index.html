A single point of ignition

A real-data run with one ignition in Forest Park during the Labor Day 2020 east wind: WPS, the complete namelist, running and reading the output.

Background: 60 fires from this project's spread model on the WUI fuel map. It switches with light/dark mode.
The case3-DWPSnamelist.inputRunOutput&fire referenceReferences

The case

One ignition at the south-east end of Forest Park, above NW Portland, during the Labor Day 2020 east-wind event, the second-worst episode in 26 years of fire weather and one with HRRR analyses available (Section 04). The point, 45.53356° N, 122.71382° W, is the start of the ensemble fire that reached the most buildings in Section 05 (71). The run starts at 00 UTC on 8 September (5 pm PDT, 7 Sept.), spins the atmosphere up for one hour, ignites at 01 UTC and follows the fire for 8 hours.

Step 1 · Preprocess with WPS

WPS: geogrid, ungrib, metgrid
# 1. geogrid: domains + static data (fuel map and terrain on the 30 m fire mesh)
cd $HOME/WPS
cp /path/to/Wildfires_forest_park/wrf/namelist.wps.forest_park namelist.wps
#    edit geog_data_path = '/path/to/WPS_GEOG'
#    edit geogrid/GEOGRID.TBL as in wrf/GEOGRID.TBL.forest_park_additions (NFUEL_CAT, ZSF, HGT_M abs_path)
./geogrid.exe                                 # -> geo_em.d01.nc, geo_em.d02.nc, geo_em.d03.nc
ncdump -h geo_em.d03.nc | grep -E "NFUEL_CAT|ZSF"    # both must be there, on the *_subgrid dimensions

# 2. ungrib: HRRR 3 km analyses, hourly, 2020-09-08 00-09 UTC (NOAA open data on AWS)
mkdir -p hrrr && cd hrrr
for h in 00 01 02 03 04 05 06 07 08 09; do
  curl -fLO https://noaa-hrrr-bdp-pds.s3.amazonaws.com/hrrr.20200908/conus/hrrr.t${h}z.wrfprsf00.grib2
done
cd ..
./link_grib.csh hrrr/hrrr.t*z.wrfprsf00.grib2
ln -sf ungrib/Variable_Tables/Vtable.raphrrr Vtable
./ungrib.exe                                  # -> HRRR:2020-09-08_00 ... _09

# 3. metgrid: weather on the model grids
./metgrid.exe                                 # -> met_em.d0{1,2,3}.2020-09-08_*.nc
ncdump -h met_em.d01.2020-09-08_00:00:00.nc | grep -E "num_metgrid_levels|num_metgrid_soil_levels"

Choices worth knowing about
  • Same sr on every domain. geogrid writes the subgrid fields with one ratio; keeping sr_x = sr_y = 5 everywhere avoids mismatched array sizes, and the fire only runs where ifire ≠ 0.
  • Spin-up before ignition. The atmosphere starts from interpolated HRRR fields; an hour lets the boundary layer and terrain flow adjust before the fire starts heating it.
  • PBL scheme or LES on d03. At 150 m the boundary layer is partly resolved (the "grey zone"). Keeping MYNN everywhere is robust; the alternative is bl_pbl_physics = 0 with diff_opt = 2, km_opt = 2 on d03 (large-eddy simulation). Try both on a short run.
  • Time step. 6 s on 1.35 km is below WRF's usual 6 × Δx(km) rule; steep terrain and the fire's updrafts can still need less. The fire CFL (S·Δt < 30 m) is far from limiting.

Step 3 · Run

set up and submit
# run directory on scratch
mkdir -p $SCRATCH/fp-single && cd $SCRATCH/fp-single
ln -sf $HOME/WRF-SFIRE/run/* .                # tables, real.exe, wrf.exe
rm -f namelist.input
cp /path/to/namelist.input .                  # the one below
cp $HOME/WRF-SFIRE/test/em_fire/namelist.fire .
sed -i 's/^ *ibeh *= *2/ibeh = 1/' namelist.fire          # Rothermel, not Balbi
ln -sf $HOME/WPS/met_em.d0*.nc .
sbatch run_wrf.slurm                          # real.exe then wrf.exe (Section 07)

Look in rsl.out.0000 for the fire's messages: the ignition at 3600 s, then the burned area and the maximum spread rate every step. rsl.error.0000 must end with SUCCESS COMPLETE WRF.

Step 4 · Look at the output

The fire fields are on the fire mesh in wrfout_d03_*: LFN (level-set function, ≤ 0 = burning or burned), TIGN_G (arrival time, s; only meaningful where LFN ≤ 0), FIRE_AREA, FGRNHFX / FGRNQFX (heat and moisture fluxes, W/m²), F_ROS, ROS, FLINEINT (fireline intensity), FUEL_FRAC, FXLONG/FXLAT, ZSF, NFUEL_CAT. The fire-mesh arrays carry sr padding cells at the far edges.

check_run.py
# quick look at the result (Python, netCDF4 + matplotlib)
from netCDF4 import Dataset
import numpy as np, matplotlib.pyplot as plt
d = Dataset("wrfout_d03_2020-09-08_00:00:00")
lon, lat = d["FXLONG"][0], d["FXLAT"][0]
ok = (lon != 0) | (lat != 0)                          # drop the sr padding at the far edges
ny, nx = np.where(ok.any(1))[0][-1] + 1, np.where(ok.any(0))[0][-1] + 1
dxf = d.DX / 5                                        # fire cell = atmospheric dx / sr = 30 m
for k, t in enumerate(d["Times"][:]):
    area = (d["LFN"][k][:ny, :nx] <= 0).sum() * dxf**2 / 1e4
    print(b"".join(t).decode(), f"burned {area:8.1f} ha   max heat flux {d['FGRNHFX'][k].max()/1e3:7.0f} kW/m2")
k = -1
plt.contour(lon[:ny, :nx], lat[:ny, :nx], d["LFN"][k][:ny, :nx], levels=[0], colors="r")
plt.quiver(d["XLONG"][0][::6, ::6], d["XLAT"][0][::6, ::6], d["U10"][k][::6, ::6], d["V10"][k][::6, ::6])
plt.title("Fire perimeter and 10 m wind, last output"); plt.savefig("perimeter.png", dpi=150)

namelist.fire

A separate file in the run directory with the fuel table (one value per fuel category). The 13 Anderson models plus “no fuel” match the Anderson-13 fuel map of this project.

EntryMeaning
ibehSpread formula: 0 MacArthur, 1 Rothermel (code default), 2 Balbi. The test file sets 2.
fuelmc_g, fuelmc_cSurface and canopy fuel moisture when the moisture model is off (0.08, 1.0).
cmbcnst, hfglHeat of combustion (17.433 MJ/kg); surface flux that ignites the canopy (170 kW/m²).
nfuelcats, no_fuel_cat13 Anderson categories; category 14 = no fuel (roads, buildings and water in the Forest Park map).
fgi, fueldepthm, savr, fuelmce, fueldens, st, seRothermel fuel properties per category: load (kg/m²), depth (m), surface-to-volume (1/ft), moisture of extinction, particle density, mineral contents.
weightBurn-time parameter, T_f = weight/0.85 s (7 for grass, 900 for timber litter).
windrfWind reduction factor from 6.1 m to mid-flame, per category.
fci_d, fct, fci, fcbr, ichapCanopy fuel load, burn time, ignition, and the chaparral switch.
fmc_gw01 … fmc_gw06Weights of the moisture classes for each category (default: all on the 1-h class).
