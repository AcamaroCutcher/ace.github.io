The script: write_tign.py

Download write_tign.py. It reads the fire-mesh coordinates from the wrfinput file (FXLONG/FXLAT, or interpolates them from XLONG/XLAT with --sr when those are not yet filled), rasterizes the perimeter, casts a ray from the ignition through every cell inside it to find where the ray leaves the perimeter, builds \(T\) as on the previous page, extends it outside, and writes TIGN_G. It prints the namelist lines to use.

perimeter ignition, step by step
# 1. an observed perimeter as GeoJSON or KML (lon, lat), e.g. from NIFC's open WFIGS perimeters,
#    an IR flight, or drawn in Google Earth (Add > Polygon, then Save Place As... .kml)
# 2. the usual WPS + real.exe for a run that STARTS BEFORE the ignition time
# 3. write the arrival-time history into the fire domain's wrfinput
cp wrfinput_d03 wrfinput_d03.orig
python write_tign.py perimeter wrfinput_d03 perimeter.geojson \
       --ign 45.5336,-122.7138 --t-ign 1800 --t-perim 12600 --sr 5
#   fire mesh 540 x 540 cells, about 30.0 x 30.0 m
#   perimeter area ... ha, T from 1800 to 12600 s
#   namelist.input &fire:
#     fire_num_ignitions  = 0,
#     fire_perimeter_time = 12600,
# 4. namelist.input, &fire (d03 column): ifire = 1, fire_num_ignitions = 0, fire_perimeter_time = 12600
# 5. run wrf.exe and check rsl.out.0000 for:
#   init_no_fire: using given ignition time to replay history to fire_perimeter_time=  12600.0
#   replay, setting the level set function
namelist.input (&fire part)
&fire
 ifire                  = 0, 0, 1,
 fire_fuel_read         = 0, 0, -1,
 fire_topo_from_atm     = 0, 0, 0,
 fire_num_ignitions     = 0, 0, 0,             ! no ignition lines with a replay
 fire_perimeter_time    = 0, 0, 12600.,        ! replay TIGN_G until 3.5 h into the run
 fire_tign_in_time      = 0, 0, 0.,            ! must stay 0: the two options exclude each other
 fire_upwinding         = 0, 0, 3,
 fire_print_msg         = 1, 1, 1,
/
Checks the code makes
  • fire_perimeter_time and fire_tign_in_time cannot both be > 0: the run stops with “fire_perimeter_time > 0 and fire_tign_in_time > 0”.
  • Arrival times are seconds after the simulation start, so --t-ign must be ≥ 0: start the run before the ignition.
  • Keep a copy of the original wrfinput; the script edits it in place.
Tested how

Both modes of write_tign.py were run on a synthetic wrfout-style file with this project's 30 m Forest Park mesh (40 ignition cells from 5 points; a 51 ha, 216-vertex perimeter: 17% of its area burned at half time and 83% by 3,500 s, in 1.5 s of run time). They have not been run on a wrfinput from real.exe here; check the printed mesh size against your e_we × sr_x before running wrf.exe.

Idealized cases

For a test with ideal.exe (no WPS), the history comes from a text file, as in the hill test's namelist.input.tign:

make input_tign_g (Python version of create_tign.m)
# idealized cases (ideal.exe) read the history from a text file instead of wrfinput:
# input_tign_g = m, n, then the m*n values row by row (test/em_fire/hill/create_tign.m)
import numpy as np
ii, jj = np.meshgrid(np.arange(1, 421), np.arange(1, 421), indexing="ij")
tign = np.sqrt(2 * (ii - 200) ** 2 + (jj - 171) ** 2) + 1      # an elliptical history, in s
with open("input_tign_g", "w") as f:
    f.write(f"{tign.shape[0]}\n{tign.shape[1]}\n")
    np.savetxt(f, tign.ravel(), fmt="%.7g")
# namelist.input (hill/namelist.input.tign): fire_perimeter_time = 20, fire_num_ignitions = 0

The NCAR code path: LFN_HIST

With ifire = 2 the perimeter is given as a level-set function in LFN_HIST and switched on by fire_is_real_perim = .true. at the start time of ignition 1 (module_fr_fire_model.F). There is no replay, so the atmosphere does not get the fire's history.

perimeter to LFN_HIST
# NCAR path (ifire = 2): put the perimeter's signed distance into LFN_HIST (negative inside)
from netCDF4 import Dataset
import numpy as np
from matplotlib.path import Path
from scipy.ndimage import distance_transform_edt
d = Dataset("wrfinput_d03", "r+")
lon, lat = np.asarray(d["FXLONG"][0]), np.asarray(d["FXLAT"][0])   # if zero, derive from XLONG/XLAT (write_tign.py)
ring = np.loadtxt("perimeter_lonlat.txt")                           # two columns: lon lat
inside = Path(ring).contains_points(np.c_[lon.ravel(), lat.ravel()]).reshape(lon.shape)
dx = 30.0                                                           # fire-mesh step (m)
sd = distance_transform_edt(~inside) * dx - distance_transform_edt(inside) * dx
d["LFN_HIST"][0] = sd.astype("float32")
d.close()
# namelist.input &fire (d03): ifire = 2, fire_is_real_perim = .true., fire_num_ignitions = 1,
#   fire_ignition_start_time1 = <time to switch the perimeter on>  (the code reads ignition 1's start time)

After the run

  • At \(t_p\) the modelled perimeter (LFN = 0) must coincide with the observed one: overlay both in Google Earth with the converter of Section 13.
  • Look at the wind and vertical velocity on d03 during the replay: an in-draft toward the fire and a plume should have formed by \(t_p\).
  • When the next perimeter arrives, compare it with the forecast at that time, then restart from the new one (cycling, as WRFx does operationally).
