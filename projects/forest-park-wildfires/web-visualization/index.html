WRFx: the OpenWFM web system

WRFx is the system the WRF-SFIRE developers use to run forecasts for real fires and show them in a browser. It has three parts (OpenWFM wiki, Running WRF-SFIRE with real data in the WRFx system):

PartWhat it isRepository
wrfxpyPython system on the cluster: fetches weather (HRRR, NAM, GFS, NARR, CFSR), builds namelists, runs WPS / real / WRF-SFIRE through the queue, post-processes wrfout to geolocated PNG/KMZ and uploads them.openwfm/wrfxpy
wrfxwebStatic web viewer for the uploaded products (a public demo runs at demo.openwfm.org).openwfm/wrfxweb
wrfxctrlFlask web app to submit and monitor jobs (start a fire from a map click).openwfm/wrfxctrl

Install wrfxpy and run a job

wrfxpy
# on the cluster, in your home directory
git clone https://github.com/openwfm/wrfxpy && cd wrfxpy
conda create -n wrfx python=3.8 && conda activate wrfx
conda install -c conda-forge gdal -y
conda install -c conda-forge netcdf4 h5py pyhdf pygrib f90nml lxml simplekml pytz pandas scipy -y
conda install -c conda-forge basemap paramiko dill psutil flask wgrib2 -y
pip install MesoPy python-cmr shapely==2
cp etc/conf.json.initial etc/conf.json        # paths to WPS, WRF-SFIRE, WPS_GEOG, workspace, "qsys"
cp etc/tokens.json.initial etc/tokens.json    # API tokens (MesoWest, NASA Earthdata) if you use those sources
#   etc/clusters.json: how to submit jobs on your cluster (qsub/sbatch command, script template)
./simple_forecast.sh                          # answers questions, writes jobs/experiment.json
./forecast.sh jobs/experiment.json >& logs/experiment.log &

Post-process an existing run for the viewer

postprocess.sh
# turn an existing wrfout into the web viewer's products (PNG + KMZ + a JSON catalog)
cd wrfxpy && conda activate wrfx
./postprocess.sh /path/to/wrfout_d03_2020-09-08_00:00:00 FGRNHFX,FIRE_AREA,F_ROS,T2,WINDVEC products/forestpark
#  usage (src/vis/postprocess.py): <wrfout_path> <var_instr> <prefix> [skip]
#  var_instr: comma-separated variable names, or @file.json with per-variable options

Variables wrfxpy knows (from src/vis/var_wisdom.py) include T2, PSFC, WINDSPD, WINDVEC, FIRE_AREA, FGRNHFX (log heat flux), F_ROS, FLINEINT, FMC_G, NFUEL_CAT, ZSF and SMOKE_INT (vertically integrated smoke). Each is rendered as a transparent PNG with a colour bar and packed into KMZ, plus a JSON manifest that wrfxweb reads.

Set up wrfxweb

wrfxweb and the shuttle
# on the web server (passwordless ssh from the cluster)
git clone https://github.com/openwfm/wrfxweb.git
cp wrfxweb/etc/conf.json.template wrfxweb/etc/conf.json
#   "url_root": "https://your.server/your_id", "organization": "...", "flags": []
mkdir wrfxweb/fdds/simulations                # serve wrfxweb/fdds over https (nginx)
# back on the cluster, in wrfxpy/etc/conf.json, tell wrfxpy where to upload:
#   "shuttle_ssh_key": "/path/to/id_rsa", "shuttle_remote_user": "your_id",
#   "shuttle_remote_host": "your.server",
#   "shuttle_remote_root": "/home/your_id/wrfxweb/fdds/simulations",
#   "shuttle_lock_path": "/tmp/your_id"

The OpenWFM team hosts accounts on demo.openwfm.org on request (see the wiki); otherwise any Linux server with nginx and https works. 2 cores and 4 GB RAM are enough; simulations take several GB each.

Or: a small viewer of your own

If you only need to show a finished run, the converter of Section 13 writes perimeters.geojson; a dozen lines of Leaflet give a web map with a time slider, hostable on GitHub Pages like this site:

viewer.html
<!-- a minimal time-slider viewer for perimeters.geojson (from Section 13's converter) -->
<div id="map" style="height:70vh"></div><input id="t" type="range" min="0" value="0" style="width:100%">
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css">
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>
<script>
const map = L.map('map').setView([45.57, -122.77], 12);
L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {attribution: '© OpenStreetMap'}).addTo(map);
fetch('perimeters.geojson').then(r => r.json()).then(g => {
  const times = [...new Set(g.features.map(f => f.properties.time))].sort();
  const slider = document.getElementById('t'); slider.max = times.length - 1;
  let layer = null;
  const show = i => {
    if (layer) layer.remove();
    layer = L.geoJSON(g, {filter: f => f.properties.time === times[i],
                          style: {color: '#d95926', weight: 2, fillOpacity: 0.3}}).addTo(map);
  };
  slider.oninput = () => show(+slider.value); show(0);
});
</script>
