Containers & Docker

What containers are, why nearly all modern software ships in them, and how to use Docker yourself: to try programs without installing them, to run websites and databases, to host AI models and keep AI agents in a sandbox, and to take your research environment to a supercomputer.

Try it first

Docker in your browser

Click the suggested commands in order, or type your own. Watch the right-hand side: that is what Docker is doing on your computer.

8 lessons

Lessons

Lessons 01 to 03 are the foundation; after them, jump to whichever of 04 to 07 matches what you want to run. Each lesson has interactive parts and ends with a short quiz.

What you need A computer with Docker (lesson 01 shows how to install it) and a terminal. No programming is needed for lessons 01, 02 and 04; lessons 03, 05 and 06 use small Python examples that are explained line by line.
About the examples

The Python examples were checked locally: the web apps with Flask's test client and the agent's tool loop against the Anthropic SDK with a mock server. YAML files were validated. The Docker commands and builds follow current documentation but were not run on this machine, so if an image tag has moved on, use the newer one. All files: python-app, fortran, static-site, web-stack, ollama, agent, devcontainer, apptainer.
