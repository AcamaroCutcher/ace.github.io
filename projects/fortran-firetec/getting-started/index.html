Why Fortran?

Fortran (FORmula TRANslation, 1957) is the oldest high-level language still in heavy use, and for one reason: it was designed for numerical work on arrays, and compilers have had sixty years to make that fast. Weather and climate models (WRF, the model under WRF-SFIRE), ocean and earthquake codes, and LANL's fire model HIGRAD/FIRETEC are written in it. Modern Fortran (the 1990, 2003, 2008, 2018 and 2023 standards) is not the punch-card language of FORTRAN 77: it has free-form source, modules, dynamic arrays, whole-array operations, pure functions and built-in parallel features.

This course teaches the parts of Fortran you need to read, run and change FIRETEC, whose open source code is on GitHub (Fortran 90 with MPI, about 12,000 lines). Every example is a complete program you can download, and most mirror a piece of FIRETEC. The physics behind the code is in Section 15 of the Forest Park project.

Install a compiler

You need gfortran (part of GCC, free), and later an MPI library and CMake to build FIRETEC.

SystemCommands
macOS (Homebrew)brew install gcc open-mpi cmake (gfortran comes with gcc)
macOS (MacPorts)sudo port install gcc15 openmpi cmake; the commands are then gfortran-mp-15, mpif90-openmpi-mp and mpirun-openmpi-mp (or run sudo port select --set gcc mp-gcc15 and sudo port select --set mpi openmpi-mp-fortran to get plain gfortran, mpif90, mpirun)
Ubuntu / Debian / WSL on Windowssudo apt install gfortran openmpi-bin libopenmpi-dev cmake liblapack-dev
HPC clustermodule avail, then for example module load gcc openmpi cmake (names differ between clusters)

Check it works with gfortran --version. On a brand-new macOS, use the newest GCC: an older one may compile but fail at the link step with invalid version number in '-mmacosx-version-min', because it does not know the new system's version number. Intel's ifx (free, in the oneAPI HPC toolkit) and NVIDIA's nvfortran are common on clusters; FIRETEC's build files support GNU, Intel and Cray compilers.

Your first program

hello.f90
! hello.f90 -- the smallest complete Fortran program
! build:  gfortran hello.f90 -o hello
! run:    ./hello
program hello
  implicit none                   ! every variable must be declared (always use this)
  print *, 'Hello from Fortran!'
end program hello

Download hello.f90

Compile and run
gfortran hello.f90 -o hello     # compile: source in, executable out
./hello                         # run

Every program starts with program name and ends with end program name. implicit none turns off a 1950s rule that made any undeclared variable starting with i–n an integer and anything else a real; with it, a typo becomes a compile error instead of a silent new variable. FIRETEC writes Implicit None in every routine: Fortran ignores upper and lower case.

Source form and compiler flags

  • Comments start with !. Long lines continue with & at the end. Free-form lines may be 132 characters (gfortran's -ffree-line-length-none lifts the limit).
  • .f90 and .F90. A capital F means "run the C preprocessor first", which allows #ifdef. FIRETEC's files are .F90 because variables.F90 chooses the precision this way:
FIRETEC-1.5.1, variables.F90 (excerpt)
module gridlist_variables
  use, intrinsic :: iso_fortran_env, only : real32,real64
  Implicit None
#ifdef DBL_PREC
  integer,parameter :: wp = 8
#else
  integer,parameter :: wp = 4
#endif
FlagWhat it does
-O2, -O3optimize (FIRETEC builds with -O2 -g)
-gkeep debugging information (line numbers in error messages, gdb)
-Wall -Wextrawarn about suspicious code: unused variables, implicit conversions
-fcheck=allcheck array bounds and more at run time: slow, but finds most bugs (FIRETEC's -DDEBUG=ON turns it on)
-fopenmpenable OpenMP threads (Lesson 08)
-DNAMEdefine a preprocessor symbol for .F90 files, e.g. -DDBL_PREC
-ccompile only, to an object file .o (for programs in several files)
Exercises
  1. Remove implicit none, add the line x = 3.7, compile and run print *, x. Then put implicit none back and read the error.
  2. Compile hello.f90 with -Wall -fcheck=all -g. Nothing changes for such a small program; keep these flags while learning.
  3. Install CMake and an MPI library now; Lesson 08 and Lesson 09 need them.
