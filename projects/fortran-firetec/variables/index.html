Types and kinds

Fortran has five built-in types: integer, real, complex, logical (.true./.false.) and character. Reals come in different kinds: 4-byte single precision (about 7 digits) and 8-byte double precision (about 16). Scientific codes name the kind once and use it everywhere, so one line switches the whole program. FIRETEC calls it wp ("working precision"): single by default, double with cmake -DDBL_PREC=ON. A literal needs the suffix too: 2.0_wp; a plain 0.1 is single precision even inside a double-precision program.

kinds.f90
! kinds.f90 -- variables, kinds, constants and arithmetic
program kinds
  use, intrinsic :: iso_fortran_env, only : real32, real64
  implicit none
  integer, parameter :: wp = real64          ! "working precision", as in FIRETEC's variables.F90
  real(wp), parameter :: pi = 3.141592653589793_wp
  real(wp), parameter :: hf = 8913480.0_wp    ! heat of reaction of wood (J/kg of products)
  integer  :: ncells
  real(wp) :: dx, area
  real(real32) :: x4
  real(real64) :: x8
  logical  :: wet
  character(len=20) :: fuel_name

  ncells = 200
  dx = 2.0_wp                                  ! the _wp suffix makes the literal double precision
  area = (ncells * dx)**2                      ! ** is the power operator
  fuel_name = 'tall grass'
  wet = .false.

  print *, 'domain side (m): ', ncells * dx
  print '(a, f10.1, a)', 'domain area: ', area / 1.0e4_wp, ' ha'
  print '(a, a)', 'fuel: ', trim(fuel_name)
  print *, 'is the fuel wet? ', wet

  ! integer division truncates; mixing kinds promotes to the wider one
  print *, '7 / 2   = ', 7 / 2
  print *, '7 / 2.0 = ', 7 / 2.0_wp

  ! single versus double precision
  x4 = 1.0_real32 / 3.0_real32
  x8 = 1.0_real64 / 3.0_real64
  print '(a, f22.18)', '1/3 in single: ', x4
  print '(a, f22.18)', '1/3 in double: ', x8
  print *, 'digits of precision: ', precision(x4), precision(x8)
  print '(a, es12.4, a)', 'heat from 1 kg of products: ', hf, ' J'
  print '(a, f8.5)', 'pi = ', pi
end program kinds

parameter makes a named constant, as in FIRETEC's real(wp) :: hf=8913480, the heat of reaction. Formats such as '(a, f10.1)' say how to print: a text, i5 an integer in 5 columns, f10.1 a real in 10 columns with 1 decimal, es12.4 scientific notation. print * lets the compiler choose.

Decisions

control.f90
! control.f90 -- if / else if and select case
program control
  implicit none
  integer, parameter :: wp = kind(1.0d0)
  real(wp) :: moisture, temperature
  integer  :: category

  moisture = 0.08_wp          ! fuel moisture as a fraction of dry mass
  temperature = 650.0_wp      ! solid temperature (K)

  if (moisture > 0.30_wp) then
    print *, 'Too wet to carry fire'
  else if (moisture > 0.15_wp) then
    print *, 'Burns slowly'
  else
    print *, 'Dry: burns readily'
  end if

  ! the same tests written with the old operators you will see in FIRETEC:  .gt. .ge. .lt. .le. .eq. .ne.
  if (temperature .ge. 600.0_wp .and. moisture .lt. 0.30_wp) print *, 'Above the pyrolysis temperature'

  category = 10
  select case (category)
  case (1:3)
    print *, 'Grass models'
  case (4:7)
    print *, 'Shrub models'
  case (8:10)
    print *, 'Timber models'
  case (11:13)
    print *, 'Slash models'
  case default
    print *, 'Unknown fuel model'
  end select
end program control

Older code, including much of FIRETEC, writes comparisons as .gt., .ge., .lt., .le., .eq., .ne.; the modern > >= < <= == /= mean the same. For example, in FIRETEC's computePsif:

      psif=0.0_wp
