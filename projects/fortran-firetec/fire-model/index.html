Building a small fire model

Everything so far in one program: a 1-D strip of grass where hot gas is carried by the wind, fuel burns, and the front moves.

The model

A 1-D resolved-volume fire

This program puts the pieces together in the way FIRETEC does, on a much smaller scale. The gas temperature T is advected by the wind with the donor-cell flux and diffused; the fuel burns at a rate that switches on with a temperature ramp ψ(T), like FIRETEC's ψs; the heat released warms the gas, which preheats the next cells downwind. There is no spread-rate formula: the front moves because of these processes. The coefficients are invented for teaching, so the speeds are not predictions.

fire1d.f90
! fire1d.f90 -- a 1-D "resolved volume" fire along a strip of grass, using FIRETEC-like pieces:
!   gas temperature T advected by the wind (donor cell) and diffused, solid fuel consumed at a rate that
!   switches on with a temperature ramp, heat released into the gas.  Writes fire1d.csv every 5 s.
! It is a teaching model with made-up coefficients, not FIRETEC.
module fire1d_mod
  implicit none
  integer, parameter :: wp = kind(1.0d0)
contains
  pure function donor(y1, y2, c) result(f)
    real(wp), intent(in) :: y1, y2, c
    real(wp) :: f
    f = max(c, 0.0_wp) * y1 + min(c, 0.0_wp) * y2
  end function donor

  elemental function psi(t) result(p)              ! fraction of the cell hot enough to react
    real(wp), intent(in) :: t
    real(wp) :: p
    p = min(1.0_wp, max(0.0_wp, (t - 400.0_wp) / 400.0_wp))
  end function psi
end module fire1d_mod

program fire1d
  use fire1d_mod
  implicit none
  integer, parameter :: n = 400                      ! 400 cells of 0.5 m = 200 m of grass
  real(wp), parameter :: dx = 0.5_wp, u = 1.0_wp, kdiff = 0.5_wp
  real(wp), parameter :: tamb = 300.0_wp, rho0 = 0.7_wp, krate = 0.6_wp
  real(wp), parameter :: heat = 1.2e3_wp             ! K of gas heating per kg/m^3 of fuel burned (illustrative)
  real(wp), parameter :: cool = 0.1_wp               ! relaxation of the gas toward ambient (1/s)
  real(wp) :: t(0:n+1), tnew(n), rhof(n), flux(0:n), dt, time, burn
  integer :: i, step, nsteps, unit

  dt = 0.4_wp * min(dx / u, dx**2 / (2.0_wp * kdiff))   ! stability: Courant and diffusion limits
  nsteps = nint(60.0_wp / dt)
  t = tamb; rhof = rho0
  t(1:10) = 1000.0_wp                                   ! ignition at the upwind end

  open(newunit=unit, file='fire1d.csv', status='replace', action='write')
  write(unit, '(a)') 'time,x,T,fuel'
  time = 0.0_wp
  do step = 0, nsteps
    if (mod(step, nint(5.0_wp / dt)) == 0) then
      do i = 1, n, 4
        write(unit, '(f6.1, ",", f6.1, ",", f8.2, ",", f7.4)') time, (i - 0.5_wp) * dx, t(i), rhof(i)
      end do
    end if
    t(0) = tamb; t(n + 1) = t(n)                        ! ghost cells: inflow on the left, outflow on the right
    do i = 0, n
      flux(i) = donor(t(i), t(i + 1), u * dt / dx)      ! advective flux through face i+1/2
    end do
    do i = 1, n                                         ! new values go to tnew so every cell sees the old t
      burn = krate * rhof(i) * psi(t(i)) * dt           ! fuel burned this step
      rhof(i) = rhof(i) - burn
      tnew(i) = t(i) - (flux(i) - flux(i - 1)) &
                + kdiff * dt / dx**2 * (t(i + 1) - 2.0_wp * t(i) + t(i - 1)) &
                + heat * burn - cool * dt * (t(i) - tamb)
    end do
    t(1:n) = tnew
    time = time + dt
  end do
  close(unit)

  print '(a, f6.1, a)', 'simulated ', time, ' s'
  print '(a, f6.1, a)', 'burned out over ', dx * count(rhof < 0.05_wp * rho0), ' m of the 200 m strip'
  print '(a, f7.1, a)', 'hottest gas now ', maxval(t(1:n)), ' K'
  print '(a)', 'wrote fire1d.csv (time, x, T, fuel)'
end program fire1d

plot_fire1d.py (needs Python with matplotlib)
"""Plot fire1d.csv written by fire1d.f90:  python3 plot_fire1d.py"""
import csv
import matplotlib.pyplot as plt

rows = list(csv.DictReader(open("fire1d.csv")))
times = sorted({float(r["time"]) for r in rows})
fig, (a1, a2) = plt.subplots(2, 1, sharex=True, figsize=(8, 6))
for k, t in enumerate(times):
    sel = [r for r in rows if float(r["time"]) == t]
    x = [float(r["x"]) for r in sel]
    c = plt.cm.inferno(0.15 + 0.7 * k / max(1, len(times) - 1))
    a1.plot(x, [float(r["T"]) for r in sel], color=c)
    a2.plot(x, [float(r["fuel"]) for r in sel], color=c, label=f"{t:.0f} s" if k % 3 == 0 else None)
a1.set_ylabel("gas temperature (K)")
a2.set_ylabel("fuel (kg/m³)")
a2.set_xlabel("distance along the strip (m)")
a2.legend(ncol=4, fontsize=8)
fig.tight_layout()
fig.savefig("fire1d.png", dpi=150)
print("wrote fire1d.png")

Things to notice in the code:

  • Ghost cells t(0) and t(n+1) carry the boundary conditions, so the update loop needs no special cases.
  • A stable time step. Explicit schemes need uΔt/Δx ≤ 1 (Courant) and κΔt/Δx² ≤ ½; the program takes 0.4 of the stricter one.
  • Old and new values. The fluxes are computed from the old temperatures before any cell is changed, and new values go to a separate array tnew, as FIRETEC computes all forcings before applying them.
  • Output for analysis. Text CSV is fine for a teaching model; FIRETEC writes unformatted binary files every frqoutput steps.

When we ran the same model in NumPy, the front settled at about 1.9 m/s and burned out roughly the first 100 m of the strip in 60 s, with gas temperatures near 1300 K behind the front.

Exercises
  1. Set the wind u to 0, 2 and 4 m/s. How does the spread rate change? Measure it from the CSV.
  2. Raise cool to 0.3 s⁻¹ (more heat lost to the surroundings). The front still advances, but the fuel no longer burns out: why?
  3. Add fuel moisture: a second array that must evaporate (taking heat from the gas) before ψ can switch on, as in FIRETEC's evaporation ramp.
  4. Make it 2-D, t(0:nx+1, 0:ny+1), with a wind at an angle, and plot the burned area.
