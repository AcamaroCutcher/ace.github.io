Agent Lab

Seven levels. In each one you write the agent program in Python, the environment runs it, and you watch the replay: a vacuum cleaner, a maze runner, a battery-powered robot, a wumpus hunter, a blind robot, and finally tools that real Claude calls. Everything runs in your browser.

~120 min1 interactive parts

Written with AI assistance (Claude) as a study companion to Russell & Norvig, Artificial Intelligence: A Modern Approach (3rd and 4th editions). It explains and links to the book; it does not replace it. Section numbers point to both editions.

Concept

2How the lab works

Every level is the loop from lesson 01, written in Python: the environment produces a percept, calls your program(percept), applies the action you return, updates the score, and repeats. Your agent.py is the agent program; the level file is the environment and the performance measure. When you press Run & check, the page sends both files to a copy of Python running in your browser (Pyodide, in a background thread), collects the score and a recording of the first episode, and replays it.

  • Memory: variables at the top of agent.py persist between calls. The level reloads your file at the start of every episode, so each episode starts fresh. That is a model-based agent's internal state.
  • Tests: each level runs several episodes (all start states, several mazes, many caves) so that an agent cannot pass by luck.
  • Same code as the lessons: the apartment and robot levels import agent_zoo.py and robot_agent.py, the exact files from lessons 02 and 09.
Run a level on your computer

Download your agent.py (button above the editor) and a level file (for example level3_maze.py and lab_common.py), put them in one folder, and run python level3_maze.py. The apartment and robot levels also need agent_zoo.py and robot_agent.py.

Build it

3After the lab

  • Swap your hand-written program for an LLM: in the robot level, write a program that sends the percept to Claude and parses its reply. That is exactly ClaudeBrain in robot_agent.py.
  • Level 7 is the bridge to real agents: the functions you wrote are tools, and the same file could become an MCP server (lesson 08) with the decorator shown there.
  • Make your own level: copy a level file, change the world and the performance measure, and send it to a friend.
Finished? Mark it, and the course home page tracks your progress (stored only in this browser).
