1Where AI and agents come from

AIMA opens by asking what AI even is. Researchers have aimed at four different targets: systems that think like humans (cognitive science), act like humans (the Turing test), think rationally (logic and the "laws of thought") and act rationally. The book, and this course, takes the last view: AI is the study of rational agents, systems that act to achieve the best expected outcome. It is the most general target, and the one that can be made precise and measured.

Click through the timeline. Notice how ideas return: search and logic from the 1950s and 60s, probability from the 80s and 90s, learning from data since the 2010s, and now all of them combined in LLM agents that plan, use tools and act.

Functions, if/else and tuples: an agent program is just a function

def reflex_vacuum(percept):
    location, status = percept          # unpack a tuple
    if status == "Dirty":
        return "Suck"
    elif location == "A":
        return "Right"
    else:
        return "Left"

for p in [("A", "Dirty"), ("A", "Clean"), ("B", "Clean")]:
    print(p, "->", reflex_vacuum(p))

State that persists: closures and classes

A model-based agent needs memory between calls. Python offers two styles; the course uses both.

def make_counter_agent():
    seen = 0                     # lives on between calls: a closure
    def program(percept):
        nonlocal seen
        seen += 1
        return f"percept #{seen}: {percept}"
    return program

agent = make_counter_agent()
print(agent("ping")); print(agent("pong"))

class CounterAgent:              # the same thing as a class
    def __init__(self):
        self.seen = 0
    def __call__(self, percept):
        self.seen += 1
        return f"percept #{self.seen}: {percept}"

a = CounterAgent()
print(a("ping")); print(a("pong"))

Queues, stacks and priority queues: the heart of search

Breadth-first search uses a queue (first in, first out), depth-first a stack (last in, first out), and uniform-cost search and A* a priority queue (smallest first). Lesson 03 is built on these three lines.

from collections import deque
import heapq

q = deque(["a", "b"]); q.append("c")
print("queue pops", q.popleft())          # a: first in, first out

stack = ["a", "b"]; stack.append("c")
print("stack pops", stack.pop())          # c: last in, first out

frontier = []
for cost, city in [(140, "Sibiu"), (118, "Timisoara"), (75, "Zerind")]:
    heapq.heappush(frontier, (cost, city))
print("priority queue pops", heapq.heappop(frontier))   # (75, 'Zerind'): cheapest first

3The math you need

Four ideas carry most of the course: expected value (rational choice under uncertainty), vectors and dot products (embeddings and attention), exp, log and softmax (turning scores into probabilities), and gradient descent (how networks learn). Each widget below makes one of them tangible.

Probability and expected value

A random variable's expected value is the average outcome you would see over many repetitions: E[X] = Σ x · P(x). A rational agent maximizes expected performance, and the Bellman equation in lesson 05 is a sum of probabilities times values. The law of large numbers says the running average of many trials approaches the expected value; watch it happen.

Vectors and the dot product

A vector is a list of numbers; in an LLM every token becomes a vector with thousands of entries (an embedding). The dot product a · b = Σ aᵢbᵢ = |a||b| cos θ measures how aligned two vectors are: large and positive when they point the same way, zero when perpendicular, negative when opposed. Attention (lesson 06) is built from dot products between query and key vectors.

exp, log and softmax

The exponential function turns any number into a positive one, and grows fast; the logarithm undoes it. Softmax uses exp to turn a list of scores into probabilities that sum to 1, exaggerating differences. Cross-entropy loss is −log of the probability given to the right answer: 0 when certain and right, large when confident and wrong.

Derivatives and gradient descent

The derivative tells you which way is downhill. Gradient descent repeatedly takes a step against the derivative: x ← x − η · f′(x), where η is the learning rate. Training a neural network is this, in billions of dimensions at once. Too small a step is slow; too large a step overshoots and diverges.
