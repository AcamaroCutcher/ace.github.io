2.1Agent = architecture + program

Lesson 01 described what an agent should do. This lesson is about how to write the program that does it. Every agent program has the same skeleton: it takes the current percept as input and returns an action. The program runs on an architecture (a computer with sensors and actuators), and the architecture runs the loop:

The loop every agent runs (the architecture's job)
while True:
    percept = sensors.read()          # perceive
    action = agent_program(percept)   # decide  <- the part AI is about
    actuators.do(action)              # act

The book then describes four basic kinds of agent program, in order of increasing generality, plus a way to make any of them improve with experience. They are not competing products; they are layers of capability. Each one adds a piece that handles something the previous one cannot.

KindAddsHandlesFails when…
Simple reflexCondition-action rules on the current perceptFully observable, simple worldsThe right action depends on something it cannot see right now
Model-based reflexInternal state + a model of how the world worksPartial observabilityFixed rules cannot express "get to X" in a new situation
Goal-basedExplicit goals + search/planning over the futureNew situations, flexible behaviorGoals conflict, or success is a matter of degree or risk
Utility-basedA utility function scoring how good states areTrade-offs, uncertainty, riskThe model or utility is wrong and nobody fixes it
LearningA critic and a learning element that improve the restUnknown environments, improving over timeFeedback is missing, misleading or gameable

2.3Simple reflex agents

A simple reflex agent maps the current percept straight to an action through condition-action rules: "if the square is dirty, suck"; "if the car in front is braking, brake". They are fast, simple and often exactly right. Biology is full of them: blinking, the knee reflex.

They have one fatal limitation: they only work if the correct decision can be made from the current percept alone, which means the environment must be effectively fully observable. In a partially observable world they can loop forever. A vacuum without a location sensor, in a clean square, whose rule says "move Left", will bump into the left wall forever. The book's fix is randomization: move in a random direction. That is what the "Simple reflex" agent below does, and why it wanders.

Concept3e/4e §2.4

2.4Model-based reflex agents

To handle partial observability, the agent keeps internal state: its best guess about the parts of the world it cannot currently see. Updating that state needs two kinds of knowledge:

  • a transition model: how the world changes, both by itself and as a result of the agent's actions ("if I move North and there is no wall, I am now one square north");
  • a sensor model: how the state of the world shows up in percepts ("if a neighbor is a wall, the bump sensor in that direction is on").

In the grid world below, the model-based agent remembers its position and every square and wall it has seen. Its rule is still a reflex ("if there is an unvisited neighbor, go there"), but now the rule can talk about remembered things.

Connection to LLM agents

For Claude Code, the internal state is the context window: every file it has read and command it has run is still "in memory" for later decisions. When the context fills up, the agent must summarize (compaction) and some state is lost, exactly the trade-off a robot faces when its map gets too big.

Concept3e/4e §2.4

2.5Goal-based agents

Knowing the state is not always enough to know what to do. At a junction, a taxi can turn left, right or go straight; the right answer depends on where the passenger wants to go. A goal-based agent has explicit goals and chooses actions by thinking about the future: "what will happen if I do A? does that get me closer to the goal?" When the answer needs a sequence of actions, this is search (lesson 03) or planning.

Goal-based agents are less efficient per decision than reflexes, but far more flexible: change the goal and the same agent does something new, without rewriting rules. The goal-based vacuum below uses breadth-first search to plan a route to the nearest unexplored square, so it never wanders.

Concept3e/4e §2.4

2.6Utility-based agents

Goals are binary: achieved or not. But there are many ways to reach a goal, and some are quicker, safer, cheaper or more reliable. A utility function scores how desirable a state is, so the agent can trade off conflicting goals (speed vs. safety) and, under uncertainty, choose the action with the highest expected utility. The book argues that a rational agent behaves as if it maximizes expected utility.

The goal-based vacuum below cleans quickly, then runs out of battery in a far room and is lost (−50). The utility-based vacuum has the same search ability but also asks "if I go there, can I still get back to the dock?". It loses some time recharging and finishes with the highest score: that trade-off is what utility is for.

2.7Learning agents

Any of the four types can be built to learn. A learning agent has four parts:

  • the performance element: the agent we have been describing, which picks actions;
  • the critic: compares outcomes against a fixed performance standard and gives feedback (a reward, a score, a human rating);
  • the learning element: uses that feedback to improve the performance element;
  • the problem generator: suggests exploratory actions that may be worse now but teach something new.

Lesson 05 builds one (Q-learning). Lesson 06 shows that LLMs are built by exactly this scheme: during training, a critic (next-token loss, then human preference ratings or a reward model in RLHF, or principles in constitutional AI) drives a learning element (gradient descent) that improves the performance element (the network). Once deployed, Claude does not keep learning from conversations; its "learning" happened during training.

2.8Five agents, one apartment

Same world, same sensors, same battery. Only the agent program changes.

What to notice
  • Random and simple reflex forget everything, so they revisit the same squares and miss whole rooms.
  • Model-based remembers but only reacts to its neighbors; in a dead end it falls back to random moves.
  • Goal-based searches for the nearest unexplored square: efficient, until the battery runs out far from the dock.
  • Utility-based plans the same way but refuses any plan it cannot return from, and recharges.

2.9Where does Claude fit?

The same taxonomy describes an LLM agent like Claude Code.

AIMA componentIn Claude Code (lesson 07)
PerceptsYour messages and the results of tool calls (file contents, command output, errors)
ActuatorsTool calls: read/edit files, run shell commands, search; text replies
Internal state (model-based)The context window: the whole conversation, including every tool result so far
Transition / world modelKnowledge learned in training: what git does, how Python errors look, what a test is
Goal (goal-based)Your request ("fix the failing test"), plus the system prompt's instructions
Utility (utility-based)Implicit preferences from training: correct, minimal, safe, readable changes; asking before risky actions
Learning elementOnly during training (pretraining, fine-tuning, RLHF/Constitutional AI). Not while it works for you.
Agent programThe LLM plus the harness loop around it. The model proposes; the harness executes and enforces permissions.
Key idea

An LLM by itself is a function from text to a probability distribution over the next token. It becomes an agent only when a program (the harness) feeds it percepts, lets it choose actions from a set of tools, executes them, and loops. That is lesson 07.

2.10The agent zoo in Python

The simulator above is a port of this file. Both use the same random number generator (mulberry32), so Benchmark 20 worlds in the widget prints exactly the numbers below. Read the agent classes in order: each one is a small extension of the previous.

agent_zoo.pyDownload
"""
agent_zoo.py - the five kinds of agent program from AIMA Section 2.4, in one grid world.

A robot vacuum lives in a small apartment. It is PARTIALLY OBSERVABLE: the robot only senses
whether its own square is dirty, which of its four neighbors are walls, whether it is on the
charging dock, and its battery level. Each move or suck costs 1 battery. Running out of
battery away from the dock ends the run with a -50 penalty. Each dirty square cleaned is +10.

    RandomAgent         ignores its percepts
    ReflexAgent         simple reflex: suck if dirty, else move to a random open neighbor
    ModelReflexAgent    model-based reflex: remembers the map, prefers unvisited neighbors
    GoalAgent           goal-based: SEARCHES (breadth-first) for the nearest unexplored square
    UtilityAgent        utility-based: like GoalAgent, but weighs battery risk and recharges

The random numbers come from mulberry32, the same generator the web page uses, so the
benchmark printed here matches the "Benchmark 20 worlds" button in lesson 02 exactly.

Run:  python agent_zoo.py
No packages needed.
"""
from collections import deque

MAP = [
    "##############",
    "#D...#.......#",
    "#....#..##...#",
    "#.........#..#",
    "###.###...#..#",
    "#.....#......#",
    "#..#..####.###",
    "#..#.........#",
    "##############",
]
DIRS = {"N": (0, -1), "E": (1, 0), "S": (0, 1), "W": (-1, 0)}
ORDER = ["N", "E", "S", "W"]
MAX_BATTERY, STEPS, DIRT_P = 100, 400, 0.3


def mulberry32(seed):
    a = seed & 0xFFFFFFFF

    def rnd():
        nonlocal a
        a = (a + 0x6D2B79F5) & 0xFFFFFFFF
        t = a
        t = ((t ^ (t >> 15)) * (t | 1)) & 0xFFFFFFFF
        t ^= (t + (((t ^ (t >> 7)) * (t | 61)) & 0xFFFFFFFF)) & 0xFFFFFFFF
        return ((t ^ (t >> 14)) & 0xFFFFFFFF) / 4294967296
    return rnd


# ------------------------------------------------------------------------- environment
class World:
    def __init__(self, seed):
        rnd = mulberry32(seed)
        self.walls, self.dirt = set(), set()
        for y, row in enumerate(MAP):
            for x, ch in enumerate(row):
                if ch == "#":
                    self.walls.add((x, y))
                elif ch == "D":
                    self.dock = (x, y)
                elif rnd() < DIRT_P:
                    self.dirt.add((x, y))
        self.total_dirt = len(self.dirt)
        self.pos, self.battery, self.score, self.dead, self.cleaned = self.dock, MAX_BATTERY, 0, False, 0

    def percept(self):
        x, y = self.pos
        return {"dirty": self.pos in self.dirt,
                "walls": {d: (x + dx, y + dy) in self.walls for d, (dx, dy) in DIRS.items()},
                "dock": self.pos == self.dock, "battery": self.battery}

    def execute(self, action):
        if self.dead:
            return
        if action in DIRS:
            dx, dy = DIRS[action]
            nxt = (self.pos[0] + dx, self.pos[1] + dy)
            if nxt not in self.walls:
                self.pos = nxt
            self.battery -= 1
        elif action == "Suck":
            if self.pos in self.dirt:
                self.dirt.discard(self.pos)
                self.score += 10
                self.cleaned += 1
            self.battery -= 1
        elif action == "Dock" and self.pos == self.dock:
            self.battery = MAX_BATTERY
        if self.battery <= 0 and self.pos != self.dock:
            self.dead = True
            self.score -= 50


# ------------------------------------------------------------------------- agents
class RandomAgent:
    def __init__(self, rnd):
        self.rnd = rnd

    def __call__(self, p):
        return (ORDER + ["Suck"])[int(self.rnd() * 5)]


class ReflexAgent:
    def __init__(self, rnd):
        self.rnd = rnd

    def __call__(self, p):
        if p["dirty"]:
            return "Suck"
        open_dirs = [d for d in ORDER if not p["walls"][d]]
        return open_dirs[int(self.rnd() * len(open_dirs))]


class ModelReflexAgent:
    """Internal state: where I am (dead reckoning from a known start) and the map seen so far."""

    def __init__(self, rnd):
        self.rnd, self.pos, self.free, self.walls, self.visited = rnd, (0, 0), {(0, 0)}, set(), {(0, 0)}

    def update(self, p):                           # UPDATE-STATE: fold the percept into the model
        x, y = self.pos
        self.visited.add(self.pos)
        for d, (dx, dy) in DIRS.items():
            (self.walls if p["walls"][d] else self.free).add((x + dx, y + dy))

    def move(self, d):                             # predicted effect of our own action
        dx, dy = DIRS[d]
        self.pos = (self.pos[0] + dx, self.pos[1] + dy)
        return d

    def __call__(self, p):
        self.update(p)
        if p["dirty"]:
            return "Suck"
        x, y = self.pos
        for d in ORDER:                            # rule: prefer a neighbor I have never visited
            dx, dy = DIRS[d]
            if not p["walls"][d] and (x + dx, y + dy) not in self.visited:
                return self.move(d)
        open_dirs = [d for d in ORDER if not p["walls"][d]]
        return self.move(open_dirs[int(self.rnd() * len(open_dirs))])


def bfs(start, goal_test, free):
    """Breadth-first search over known-free squares. Returns the list of moves, or None."""
    q, parent = deque([start]), {start: None}
    while q:
        c = q.popleft()
        if goal_test(c):
            path = []
            while parent[c]:
                c, d = parent[c]
                path.append(d)
            return path[::-1]
        for d in ORDER:
            dx, dy = DIRS[d]
            n = (c[0] + dx, c[1] + dy)
            if n in free and n not in parent:
                parent[n] = (c, d)
                q.append(n)
    return None


class GoalAgent(ModelReflexAgent):
    """Goal: every reachable square explored. Plans with search instead of reacting."""

    def plan_to_frontier(self):
        return bfs(self.pos, lambda c: c not in self.visited, self.free)

    def __call__(self, p):
        self.update(p)
        if p["dirty"]:
            return "Suck"
        path = self.plan_to_frontier()
        if path:
            return self.move(path[0])
        home = bfs(self.pos, lambda c: c == (0, 0), self.free)
        return self.move(home[0]) if home else ("Dock" if p["dock"] else "NoOp")


class UtilityAgent(GoalAgent):
    """Prefers plans with the highest expected utility: +10 per dirt, -50 if the battery dies.
    In practice: never start an action unless it can still get home afterwards."""

    def __call__(self, p):
        self.update(p)
        home = bfs(self.pos, lambda c: c == (0, 0), self.free)
        d_home = len(home)
        if p["dock"] and p["battery"] < MAX_BATTERY and self.recharging(p):
            return "Dock"
        if p["dirty"] and p["battery"] - 1 > d_home:
            return "Suck"
        path = self.plan_to_frontier()
        if path:
            target = self.target_of(path)
            back = len(bfs(target, lambda c: c == (0, 0), self.free) or [])
            if len(path) + back + 1 < p["battery"]:      # enough battery to get there AND back
                return self.move(path[0])
        if home:
            return self.move(home[0])                    # go home: recharge or finish
        return "Dock" if p["dock"] else "NoOp"

    def recharging(self, p):
        return p["battery"] < MAX_BATTERY and bfs(self.pos, lambda c: c not in self.visited, self.free) is not None

    def target_of(self, path):
        x, y = self.pos
        for d in path:
            dx, dy = DIRS[d]
            x, y = x + dx, y + dy
        return (x, y)


AGENTS = [("Random", RandomAgent), ("Simple reflex", ReflexAgent), ("Model-based reflex", ModelReflexAgent),
          ("Goal-based", GoalAgent), ("Utility-based", UtilityAgent)]


def run(agent_cls, seed):
    w = World(seed)
    agent = agent_cls(mulberry32(seed + 1000))
    for _ in range(STEPS):
        if w.dead:
            break
        w.execute(agent(w.percept()))
    return w


if __name__ == "__main__":
    print(f"20 worlds, {STEPS} steps each, battery {MAX_BATTERY}, +10 per dirt, -50 if the battery dies away from the dock\n")
    print(f"{'agent':20s} {'avg score':>9s} {'dirt cleaned':>13s} {'battery deaths':>15s}")
    for name, cls in AGENTS:
        runs = [run(cls, seed) for seed in range(1, 21)]
        score = sum(r.score for r in runs) / len(runs)
        frac = sum(r.cleaned / r.total_dirt for r in runs) / len(runs)
        deaths = sum(r.dead for r in runs)
        print(f"{name:20s} {score:9.1f} {100 * frac:12.0f}% {deaths:15d}")

Exercises
  1. Give the reflex agent one bit of memory ("the direction I came from") and forbid it from going straight back. How much does that help? Which agent type is it now?
  2. The utility agent's safety margin is the + 1 in len(path) + back + 1 < battery. What happens with a margin of 0? Of 20?
  3. Make the world dynamic: each step, any clean square becomes dirty with probability 0.002. Which agent copes best, and why does "explore everything once" stop being a good goal?
