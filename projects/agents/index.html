2How this course works

The book is excellent but dense, and its code lives in a separate repository, which makes it hard to see how an equation turns into a program. This course puts the three side by side: the idea in plain words, a widget you can poke until the idea is obvious, and the Python that implements it, with the book's pseudocode and the code linked line by line.

Read a chapter section of AIMA, then do the matching lesson (each section is labeled with its section number in the 3rd and 4th editions). Or read the lessons first and use the book for depth. Terms with a dotted underline, like agent or rational agent, show a definition when you hover or tap them.

Three ways to learn by doing
  • Widgets on every page: simulations, step-through algorithms, things to drag and paint.
  • ▶ Run and ✎ Edit on the Python examples: the code runs in your browser (Python compiled to WebAssembly by the Pyodide project), so you can change a line and see what happens without installing anything. The first run downloads about 10 MB.
  • 🔑 Live mode in lessons 07 and 09: paste your own Anthropic API key and watch real Claude drive a coding agent and the robot simulator, every message visible.

Press / or Ctrl K anywhere to search the course; n and p move to the next and previous lesson.
