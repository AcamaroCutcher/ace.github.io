5.1Sequential decisions in a stochastic world

In lesson 03 actions were deterministic, so a plan (a fixed sequence of actions) was a solution. Now actions are unreliable. In the book's 4×3 world, an action moves the agent in the intended direction with probability 0.8, and at right angles with probability 0.1 each; bumping into a wall leaves it where it is. Two squares are terminal: +1 and −1. Every other square gives a small "living reward" R(s) = −0.04, so the agent wants to finish, but not in the −1 square.

This is a Markov decision process (MDP): a fully observable, stochastic, sequential problem defined by

  • a set of states s and actions A(s);
  • a transition model P(s′ | s, a), the probability of reaching s′ from s with action a (Markov: it depends only on the current state, not the history);
  • a reward function: R(s) in the 3rd edition, R(s, a, s′) in the 4th (same idea, slightly more general).

A solution is a policy π: an action for every state, so that wherever chance puts the agent, it knows what to do next. The optimal policy π* maximizes the expected total reward.

5.2Why a fixed plan is not enough

The obvious plan from the start square [1,1] is Up, Up, Right, Right, Right. In a deterministic world it always works. Here, the book computes its success probability as 0.8⁵ + 0.1⁴ × 0.8 = 0.32776 (the second term is the lucky path that slides the other way round). Run it a thousand times, and compare with an agent that follows the optimal policy and simply reacts to wherever it lands.

5.3Utilities and the Bellman equation

The utility of a state, U(s), is the expected sum of (discounted) rewards the agent will collect from s onward if it acts optimally. A discount factor γ between 0 and 1 makes rewards sooner worth more than rewards later; with γ = 1 and terminal states, the plain sum is fine.

Utilities satisfy a beautiful recursive equation: the utility of a state is its immediate reward, plus the discounted expected utility of the next state, if the agent picks the best action:

U(s) = R(s) + γ · maxa Σs′ P(s′ | s, a) U(s′)The Bellman equation (3rd-edition notation; the 4th writes the reward as R(s, a, s′) inside the sum). Once you know U, the optimal policy picks the action that achieves the max.

There is one such equation per state, and they are nonlinear (because of the max), so we cannot just solve a linear system. Instead, value iteration starts from U = 0 and applies the equation as an update rule to every state, over and over. Each sweep propagates information one step further from the terminal states, and the values converge to the true utilities.

Policy iteration (3e §17.3, 4e §17.2) is the main alternative: start with any policy, compute its exact utilities (now a linear system, because the action is fixed), then improve the policy greedily, and repeat. It often converges in a handful of iterations.

5.7Reinforcement learning: no model, only experience

Value iteration needs the transition model P(s′|s,a) and the rewards. What if the agent does not know them? It has to learn from experience: try actions, observe what happens, collect rewards. That is reinforcement learning. The agent is a learning agent whose critic is the reward signal.

Q-learning learns an action-value function Q(s, a): the expected utility of doing a in s and acting optimally afterwards. It never builds a model. After every step it nudges its estimate toward a better one, using the reward it just got and its own estimate of the next state (a temporal-difference update):

Q(s,a) ← Q(s,a) + α · [ R(s) + γ · maxa′ Q(s′,a′) − Q(s,a) ]α is the learning rate. The bracket is the "surprise": how much better or worse things went than expected.

It also faces the exploration-exploitation dilemma: always taking the action that currently looks best (exploiting) can lock in a mediocre habit, while exploring costs reward now. The simplest compromise is ε-greedy: with probability ε take a random action. This is the problem generator of the learning-agent diagram (lesson 02).

5.9From Q-learning to training Claude

The same ideas, at a vastly larger scale, are part of how modern LLMs are trained after pretraining:

  • The policy is the language model. Its "action" is the next token (or a whole response); its "state" is the text so far.
  • The reward comes from feedback. In RLHF, people compare pairs of responses; a reward model learns to predict their preferences; the LLM is then optimized with policy-gradient RL to produce responses the reward model scores highly. In Anthropic's Constitutional AI, much of the feedback comes from an AI model guided by a written set of principles. Labs also use RL on tasks whose results can be checked automatically, such as code that must pass tests.
  • Exploration and reward hacking appear exactly as in this chapter. A policy optimized against an imperfect reward finds its loopholes (the vacuum that dumps dirt to suck it up again). A lot of real work goes into rewards that measure what we actually want.
Key idea

RL turns "here is how good that was" into better behavior without anyone writing down the right action. That is why it scales to problems, like writing helpful answers, where nobody can write the policy by hand.

"""
mdp.py - AIMA Chapter 17 (Markov decision processes) and the Q-learning agent of
Chapter 21 (3e) / 22 (4e), on the book's 4x3 world (Figure 17.1).

    . . . +1        (4,3) is a terminal state worth +1, (4,2) is terminal and worth -1,
    . # . -1        (2,2) is a wall. Every other state gives the "living reward" R(s).
    S . . .         Actions go in the intended direction with probability 0.8, and at
                    right angles with probability 0.1 each. Bumping a wall: stay put.

Run:  python mdp.py
Needs no packages.
"""
import random

COLS, ROWS = 4, 3
WALLS = {(2, 2)}
TERMINALS = {(4, 3): 1.0, (4, 2): -1.0}
ACTIONS = {"Up": (0, 1), "Down": (0, -1), "Left": (-1, 0), "Right": (1, 0)}
ARROWS = {"Up": "^", "Down": "v", "Left": "<", "Right": ">"}
SIDEWAYS = {"Up": ("Left", "Right"), "Down": ("Left", "Right"),
            "Left": ("Up", "Down"), "Right": ("Up", "Down")}

STATES = [(x, y) for x in range(1, COLS + 1) for y in range(1, ROWS + 1) if (x, y) not in WALLS]


def move(s, a):
    dx, dy = ACTIONS[a]
    t = (s[0] + dx, s[1] + dy)
    if t in WALLS or not (1 <= t[0] <= COLS and 1 <= t[1] <= ROWS):
        return s
    return t


def transitions(s, a):
    """P(s' | s, a) as a list of (probability, s')."""
    left, right = SIDEWAYS[a]
    return [(0.8, move(s, a)), (0.1, move(s, left)), (0.1, move(s, right))]


def reward(s, living):
    return TERMINALS.get(s, living)


def value_iteration(living=-0.04, gamma=1.0, eps=1e-6, verbose=False):
    """AIMA 3e Figure 17.4: repeat the Bellman update until utilities stop changing.

        U(s) <- R(s) + gamma * max_a sum_s' P(s'|s,a) U(s')
    """
    U = {s: 0.0 for s in STATES}
    it = 0
    while True:
        it += 1
        U2, delta = {}, 0.0
        for s in STATES:
            if s in TERMINALS:
                U2[s] = TERMINALS[s]
            else:
                U2[s] = reward(s, living) + gamma * max(
                    sum(p * U[t] for p, t in transitions(s, a)) for a in ACTIONS)
            delta = max(delta, abs(U2[s] - U[s]))
        U = U2
        if verbose and it <= 3:
            print(f"after iteration {it}:"); show_values(U)
        # stopping rule from the book; with gamma = 1 we just use a small absolute threshold
        if delta < (eps * (1 - gamma) / gamma if gamma < 1 else eps):
            return U, it


def best_policy(U):
    return {s: max(ACTIONS, key=lambda a: sum(p * U[t] for p, t in transitions(s, a)))
            for s in STATES if s not in TERMINALS}


def show_values(U):
    for y in range(ROWS, 0, -1):
        row = []
        for x in range(1, COLS + 1):
            row.append("  ####" if (x, y) in WALLS else f"{U[(x, y)]:+6.3f}")
        print("   " + " ".join(row))


def show_policy(pi):
    for y in range(ROWS, 0, -1):
        row = ""
        for x in range(1, COLS + 1):
            s = (x, y)
            row += " # " if s in WALLS else (" +1" if TERMINALS.get(s) == 1 else " -1" if s in TERMINALS else f" {ARROWS[pi[s]]} ")
        print("   " + row)


# ------------------------------------------------------------------------- Q-learning
def q_learning(episodes=5000, living=-0.04, gamma=1.0, alpha=0.1, epsilon=0.1, seed=1):
    """A model-free agent: it never sees P(s'|s,a); it only tries actions and observes results.

        Q(s,a) <- Q(s,a) + alpha * (r + gamma * max_a' Q(s',a') - Q(s,a))
    """
    rng = random.Random(seed)
    Q = {(s, a): 0.0 for s in STATES for a in ACTIONS}
    for s, r in TERMINALS.items():
        for a in ACTIONS:
            Q[(s, a)] = r
    for _ in range(episodes):
        s = (1, 1)
        while s not in TERMINALS:
            if rng.random() < epsilon:                                   # explore
                a = rng.choice(list(ACTIONS))
            else:                                                        # exploit
                a = max(ACTIONS, key=lambda b: Q[(s, b)])
            r_ = rng.random()                                            # the world rolls the dice
            p_cum, s2 = 0.0, s
            for p, t in transitions(s, a):
                p_cum += p
                if r_ < p_cum:
                    s2 = t
                    break
            target = reward(s, living) + gamma * max(Q[(s2, b)] for b in ACTIONS)
            Q[(s, a)] += alpha * (target - Q[(s, a)])
            s = s2
    return Q


if __name__ == "__main__":
    U, iters = value_iteration(-0.04)
    print(f"Value iteration, R(s) = -0.04, gamma = 1: converged after {iters} iterations")
    show_values(U)
    print("Optimal policy:")
    show_policy(best_policy(U))

    print("\nHow the policy changes with the living reward (AIMA Figure 17.2):")
    for living in (-2.0, -0.2, -0.04, -0.01, 0.0):
        U, _ = value_iteration(living, gamma=0.999 if living >= 0 else 1.0)
        print(f"R(s) = {living}")
        show_policy(best_policy(U))

    Q = q_learning()
    U_q = {s: max(Q[(s, a)] for a in ACTIONS) for s in STATES}
    print("\nQ-learning after 5000 episodes (estimates of the same utilities):")
    show_values(U_q)
    show_policy({s: max(ACTIONS, key=lambda a: Q[(s, a)]) for s in STATES if s not in TERMINALS})
