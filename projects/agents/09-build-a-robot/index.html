9.1Robots are agents with bodies

A robot is an agent whose actuators exert forces on the physical world and whose sensors measure it. Everything from lesson 01 applies, in its hardest form: the world is partially observable (sensors are noisy and limited), stochastic (wheels slip, batteries sag), dynamic (people move), continuous, and sometimes multiagent.

Real robots therefore split control into layers that run at different speeds. AIMA describes a three-layer architecture: a reactive layer for low-level control with millisecond loops; an executive layer that sequences behaviors; and a deliberative layer that plans, slowly, with a model of the world. Our robot maps onto it directly:

LayerIn our robotSpeedExample
Deliberative (brain)The LLM agent: Claude via the API, or a local model~1–10 s per decision"Explore the room, then report its size"
Executive (body)Body in robot_agent.py: tool validation, unit conversion, sequencing~10 msdrive(25) → check clearance → motors for 1.25 s
Reactive (reflexes)The Arduino firmware: motion timeout and obstacle stop~1 msSomething closer than 15 cm → stop now
Key idea

Never put a fast safety reflex behind a slow brain. An LLM round trip takes seconds; at 20 cm/s the robot moves tens of centimeters in that time. The firmware's obstacle stop is a simple reflex agent (lesson 02), and that is exactly right for its job. This is also the idea behind Rodney Brooks' subsumption architecture.

9.2Drive the simulated robot

A 2 × 2 m room with a box in it, exactly as in SimRobot. The robot sees only straight ahead (the beam); each measurement adds a dot to its map. Four ways to control it:

  • Manual tools: you are the brain. Call the same four tools the LLM gets. Try driving into the box: the body refuses.
  • Reflex brain: OfflineBrain, "drive if clear, else turn left". Its output is identical to python robot_agent.py --sim.
  • LLM-style plan (replay): a scripted transcript of the kind of step-by-step reasoning an LLM produces for "explore the room and tell me how big it is", executed live through the same safety layer. It is a replay for illustration, not a live model.
  • Live Claude: paste your own API key and Claude itself drives, one API call per step, through the same body and safety checks. Give it your own goals.

9.3The software: robot_agent.py

One file, three swappable parts: the robot (SimRobot or SerialRobot), the body (validation), and the brain (OfflineBrain, ClaudeBrain, OllamaBrain). Develop with --sim --brain offline, then swap one part at a time.

"""
robot_agent.py - an LLM agent that drives a small wheeled robot.

Three layers, from slow to fast (the same split real robots use):

    1. the BRAIN   an LLM that turns a goal ("find the door") into tool calls     seconds per step
    2. the BODY    this file: validates each tool call and turns it into          milliseconds
                   motor commands; refuses anything outside safe limits
    3. REFLEXES    the Arduino firmware: motion timeouts and obstacle stops       microseconds
                   that work even if layers 1 and 2 crash

Backends (the robot):
    --sim                 a simulated robot in a 2 x 2 m room (default; no hardware needed)
    --port /dev/ttyACM0   a real robot running robot_firmware.ino   (pip install pyserial)

Brains (the model):
    --brain offline       a hand-written reflex policy (no API, no network)        [default]
    --brain claude        Claude via the Anthropic API   (pip install anthropic)
    --brain ollama        a local model served by Ollama (no internet once the model is pulled)

Examples:
    python robot_agent.py --sim --brain offline
    python robot_agent.py --sim --brain claude "explore the room and tell me how big it is"
    python robot_agent.py --port /dev/ttyACM0 --brain ollama --model qwen3:1.7b "drive forward until something is close"

Tested here: the simulator with the offline brain, and the Claude brain against a mock API.
Not tested here: the serial backend (no robot attached) and the Ollama brain (no Ollama server).
"""
import argparse
import json
import math
import time
import urllib.request

MAX_DRIVE_CM, MAX_TURN_DEG, CLEARANCE_CM = 100, 180, 12
CM_PER_SEC, DEG_PER_SEC, SPEED = 20.0, 90.0, 150    # calibrate these on your robot!

SYSTEM = """You control a small two-wheeled robot through tools. You cannot see; your only sense
is an ultrasonic distance sensor that points forward. Move in small steps, measure often, and
never drive into something closer than the distance you plan to drive. When the goal is reached
or impossible, stop moving and report what you found in a few sentences."""

TOOLS = [
    {"name": "read_distance", "description": "Measure the distance in cm to the nearest object straight ahead.",
     "input_schema": {"type": "object", "properties": {}, "additionalProperties": False}},
    {"name": "drive", "description": f"Drive straight. Positive = forward, negative = backward. Max {MAX_DRIVE_CM} cm per call.",
     "input_schema": {"type": "object", "properties": {"cm": {"type": "number"}}, "required": ["cm"], "additionalProperties": False}},
    {"name": "turn", "description": f"Turn in place. Positive = left (counter-clockwise), negative = right. Max {MAX_TURN_DEG} degrees per call.",
     "input_schema": {"type": "object", "properties": {"degrees": {"type": "number"}}, "required": ["degrees"], "additionalProperties": False}},
    {"name": "stop", "description": "Stop the motors immediately.",
     "input_schema": {"type": "object", "properties": {}, "additionalProperties": False}},
]


# =============================================================== robots (the body's hardware)
class SimRobot:
    """A point robot in a rectangular room with one box in it. Distances come from ray casting."""

    def __init__(self):
        self.w, self.h = 200.0, 200.0                 # room size in cm
        self.box = (120.0, 60.0, 160.0, 100.0)        # an obstacle: x0, y0, x1, y1
        self.x, self.y, self.heading = 30.0, 30.0, 0.0  # start near a corner, facing +x

    def distance(self):
        best = 400.0
        dx, dy = math.cos(math.radians(self.heading)), math.sin(math.radians(self.heading))
        for t in [i * 0.5 for i in range(1, 800)]:    # march along the ray in 0.5 cm steps
            px, py = self.x + dx * t, self.y + dy * t
            x0, y0, x1, y1 = self.box
            if not (0 <= px <= self.w and 0 <= py <= self.h) or (x0 <= px <= x1 and y0 <= py <= y1):
                best = t
                break
        return round(best)

    def motors(self, left, right, ms):
        if left > 0 and right > 0 and self.distance() < 15:
            return "ERR obstacle"
        secs = ms / 1000.0
        if left == right:
            d = math.copysign(CM_PER_SEC * secs, left)
            if d > 0:
                d = min(d, max(0, self.distance() - 15))  # the firmware reflex stops it short
            self.x += d * math.cos(math.radians(self.heading))
            self.y += d * math.sin(math.radians(self.heading))
        else:
            self.heading = (self.heading + math.copysign(DEG_PER_SEC * secs, right - left)) % 360
        return "OK M"

    def stop(self):
        return "OK S"

    def pose(self):
        return f"(x={self.x:.0f} cm, y={self.y:.0f} cm, heading={self.heading:.0f} deg)"


class SerialRobot:
    """Talks to robot_firmware.ino over USB serial."""

    def __init__(self, port):
        import serial                                  # pip install pyserial
        self.ser = serial.Serial(port, 115200, timeout=2)
        time.sleep(2)                                  # most Arduinos reset when the port opens
        self.ser.reset_input_buffer()

    def _ask(self, cmd):
        self.ser.write((cmd + "\n").encode())
        while True:
            line = self.ser.readline().decode(errors="replace").strip()
            if not line:
                return "ERR no reply"
            if not line.startswith("EVENT"):           # events are printed but not answers
                return line
            print("   firmware:", line)

    def distance(self):
        reply = self._ask("D")
        return int(reply.split()[1]) if reply.startswith("D ") else 0

    def motors(self, left, right, ms):
        reply = self._ask(f"M {left} {right} {int(ms)}")
        time.sleep(ms / 1000.0 + 0.05)                # wait for the motion to finish
        return reply

    def stop(self):
        return self._ask("S")

    def pose(self):
        return "(unknown: a real robot has no GPS; that is what mapping/SLAM is for)"


# =============================================================== the body: tools with safety checks
class Body:
    def __init__(self, robot):
        self.robot = robot

    def call(self, name, args):
        """Validate, then act. Returns (text for the model, is_error)."""
        if name == "read_distance":
            return f"{self.robot.distance()} cm", False
        if name == "stop":
            return self.robot.stop(), False
        if name == "drive":
            cm = float(args.get("cm", 0))
            if abs(cm) > MAX_DRIVE_CM:
                return f"Refused: {cm} cm is more than the {MAX_DRIVE_CM} cm limit per call.", True
            if cm > 0:
                free = self.robot.distance()
                if cm > free - CLEARANCE_CM:
                    return f"Refused: only {free} cm free ahead; driving {cm} cm would hit something.", True
            ms = abs(cm) / CM_PER_SEC * 1000
            s = SPEED if cm > 0 else -SPEED
            reply = self.robot.motors(s, s, ms)
            return f"{reply}; drove {cm} cm. Now {self.robot.pose()}", reply.startswith("ERR")
        if name == "turn":
            deg = float(args.get("degrees", 0))
            if abs(deg) > MAX_TURN_DEG:
                return f"Refused: turn at most {MAX_TURN_DEG} degrees per call.", True
            ms = abs(deg) / DEG_PER_SEC * 1000
            left, right = (-SPEED, SPEED) if deg > 0 else (SPEED, -SPEED)
            reply = self.robot.motors(left, right, ms)
            return f"{reply}; turned {deg} degrees. Now {self.robot.pose()}", reply.startswith("ERR")
        return f"Unknown tool {name}", True


# =============================================================== brains
class OfflineBrain:
    """No LLM: a simple reflex agent (AIMA Ch. 2) that explores by 'drive if clear, else turn'.
    Its 'tool calls' have the same shape as an LLM's, so the rest of the program is identical."""

    def __init__(self, steps=12):
        self.left = steps
        self.measured = None

    def start(self, goal):
        pass

    def next_actions(self, last_results):
        for name, out, _err, _tid in last_results or []:
            if name == "read_distance":
                self.measured = int(out.split()[0])
        if self.left <= 0:
            return "Explored 12 steps with a reflex rule. (An LLM brain would plan instead.)", []
        self.left -= 1
        if self.measured is None:
            return "Measuring.", [("read_distance", {})]
        free, self.measured = self.measured, None
        if free > 40:
            return f"{free} cm free: driving 25 cm.", [("drive", {"cm": 25}), ("read_distance", {})]
        return f"Only {free} cm free: turning left.", [("turn", {"degrees": 90}), ("read_distance", {})]


class ClaudeBrain:
    def __init__(self, model="claude-opus-5-5"):
        import anthropic
        self.client, self.model, self.messages = anthropic.Anthropic(), model, []

    def start(self, goal):
        self.messages = [{"role": "user", "content": goal}]

    def next_actions(self, last_results):
        if last_results:
            self.messages.append({"role": "user", "content": [
                {"type": "tool_result", "tool_use_id": tid, "content": out, "is_error": err}
                for (_, out, err, tid) in last_results]})
        r = self.client.beta.messages.create(
            model=self.model, max_tokens=4000, system=SYSTEM, tools=TOOLS, messages=self.messages,
            betas=["server-side-fallback-2026-07-01"], fallbacks="default")
        self.messages.append({"role": "assistant", "content": r.content})
        text = "".join(b.text for b in r.content if b.type == "text")
        if r.stop_reason == "refusal":
            return "The model declined.", []
        return text, [(b.name, b.input, b.id) for b in r.content if b.type == "tool_use"]


class OllamaBrain:
    """A local model through Ollama's HTTP API (https://ollama.com). Pick a model tagged 'tools'.
    On a Raspberry Pi 5, models of 1-4 billion parameters are the practical size."""

    def __init__(self, model="qwen3:1.7b", url="http://localhost:11434/api/chat"):
        self.model, self.url, self.messages = model, url, []
        self.tools = [{"type": "function", "function": {"name": t["name"], "description": t["description"],
                                                         "parameters": t["input_schema"]}} for t in TOOLS]

    def start(self, goal):
        self.messages = [{"role": "system", "content": SYSTEM}, {"role": "user", "content": goal}]

    def next_actions(self, last_results):
        for name, out, _err, _tid in last_results or []:
            self.messages.append({"role": "tool", "content": out, "tool_name": name})
        body = json.dumps({"model": self.model, "messages": self.messages, "tools": self.tools, "stream": False}).encode()
        req = urllib.request.Request(self.url, body, {"Content-Type": "application/json"})
        msg = json.load(urllib.request.urlopen(req, timeout=300))["message"]
        self.messages.append(msg)
        calls = [(c["function"]["name"], c["function"].get("arguments") or {}, None) for c in msg.get("tool_calls") or []]
        return msg.get("content", ""), calls


# =============================================================== the loop
def run(brain, body, goal, max_steps=25):
    brain.start(goal)
    results = None
    for step in range(1, max_steps + 1):
        text, calls = brain.next_actions(results)
        if text:
            print(f"[{step}] brain: {text.strip()}")
        if not calls:
            break
        results = []
        for call in calls:
            name, args = call[0], call[1]
            tid = call[2] if len(call) > 2 else None
            out, err = body.call(name, args)
            print(f"      {name}({json.dumps(args)}) -> {out}")
            results.append((name, out, err, tid))
    body.robot.stop()
    print("motors stopped.")


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("goal", nargs="?", default="Explore the room. Find out roughly how big it is, then stop and report.")
    ap.add_argument("--sim", action="store_true", help="use the simulated robot (default if no --port)")
    ap.add_argument("--port", help="serial port of a robot running robot_firmware.ino")
    ap.add_argument("--brain", choices=["offline", "claude", "ollama"], default="offline")
    ap.add_argument("--model", help="model name for claude/ollama")
    a = ap.parse_args()
    robot = SerialRobot(a.port) if a.port else SimRobot()
    if a.brain == "claude":
        brain = ClaudeBrain(a.model or "claude-opus-5-5")
    elif a.brain == "ollama":
        brain = OllamaBrain(a.model or "qwen3:1.7b")
    else:
        brain = OfflineBrain()
    run(brain, Body(robot), a.goal)

robot_firmware/robot_firmware.ino (Arduino IDE: open, select your board and port, Upload)Download
/*
 * robot_firmware.ino - the "spinal cord" of a two-wheeled robot (Arduino Uno or Nano).
 *
 * The microcontroller does the fast, safety-critical work; the agent on the Raspberry Pi or
 * laptop does the slow thinking. They talk over USB serial, one text command per line:
 *
 *   M <left> <right> <ms>   run the motors (-255..255 each) for at most <ms> milliseconds, then stop
 *   S                       stop now
 *   D                       measure the distance ahead in cm with the ultrasonic sensor
 *   P                       ping (replies OK P)
 *
 * Safety lives here, below the AI, where no prompt can change it:
 *   - every motion ends on its own after <ms> (max 2000), so a crashed agent can't leave motors running
 *   - forward motion is refused, or cut, when something is closer than STOP_CM
 *
 * Hardware: TB6612FNG dual motor driver, HC-SR04 ultrasonic sensor, two DC gear motors,
 * a separate battery for the motors (share ground with the Arduino).
 * Not compiled while preparing the course: check pin numbers against your own wiring.
 */

const int PWMA = 5, AIN1 = 7, AIN2 = 8;    // left motor
const int PWMB = 6, BIN1 = 9, BIN2 = 10;   // right motor
const int STBY = 4;                        // driver standby: LOW = everything off
const int TRIG = 11, ECHO = 12;            // ultrasonic sensor

const int STOP_CM = 15;
const unsigned long MAX_MS = 2000;

unsigned long stopAt = 0;     // when the current motion must end (0 = not moving)
bool movingForward = false;
String line;

void setMotor(int pwmPin, int in1, int in2, int speed) {
  speed = constrain(speed, -255, 255);
  digitalWrite(in1, speed > 0);
  digitalWrite(in2, speed < 0);
  analogWrite(pwmPin, abs(speed));
}

void stopMotors() {
  setMotor(PWMA, AIN1, AIN2, 0);
  setMotor(PWMB, BIN1, BIN2, 0);
  stopAt = 0;
  movingForward = false;
}

int distanceCm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  unsigned long us = pulseIn(ECHO, HIGH, 25000UL);   // time out after ~4 m
  if (us == 0) return 400;                           // no echo: treat as "far"
  return (int)(us / 58UL);                           // sound: ~58 us per cm, there and back
}

void handle(String cmd) {
  cmd.trim();
  if (cmd.length() == 0) return;
  char op = cmd.charAt(0);
  if (op == 'S') {
    stopMotors();
    Serial.println("OK S");
  } else if (op == 'P') {
    Serial.println("OK P");
  } else if (op == 'D') {
    Serial.print("D ");
    Serial.println(distanceCm());
  } else if (op == 'M') {
    int left = 0, right = 0;
    long ms = 0;
    if (sscanf(cmd.c_str(), "M %d %d %ld", &left, &right, &ms) != 3 || ms <= 0) {
      Serial.println("ERR usage: M <left> <right> <ms>");
      return;
    }
    bool forward = left > 0 && right > 0;
    if (forward && distanceCm() < STOP_CM) {
      Serial.println("ERR obstacle");
      return;
    }
    setMotor(PWMA, AIN1, AIN2, left);
    setMotor(PWMB, BIN1, BIN2, right);
    stopAt = millis() + min((unsigned long)ms, MAX_MS);
    movingForward = forward;
    Serial.println("OK M");
  } else {
    Serial.println("ERR unknown command");
  }
}

void setup() {
  pinMode(PWMA, OUTPUT); pinMode(AIN1, OUTPUT); pinMode(AIN2, OUTPUT);
  pinMode(PWMB, OUTPUT); pinMode(BIN1, OUTPUT); pinMode(BIN2, OUTPUT);
  pinMode(STBY, OUTPUT); pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT);
  digitalWrite(STBY, HIGH);
  stopMotors();
  Serial.begin(115200);
  Serial.println("READY");
}

void loop() {
  while (Serial.available()) {               // read a line without blocking the loop
    char c = Serial.read();
    if (c == '\n') { handle(line); line = ""; }
    else if (line.length() < 40) line += c;
  }
  if (stopAt && (long)(millis() - stopAt) >= 0) stopMotors();              // motion timer ran out
  static unsigned long lastCheck = 0;
  if (movingForward && millis() - lastCheck > 60) {                         // reflex: obstacle ahead
    lastCheck = millis();
    if (distanceCm() < STOP_CM) { stopMotors(); Serial.println("EVENT obstacle_stop"); }
  }
}

9.5Bring-up, one layer at a time

Build bottom-up and test each layer before adding the next. When something fails, you will know which layer to look at.

  1. Motors alone. Robot on a box with the wheels in the air. Upload the firmware, open the Arduino Serial Monitor at 115200 baud (newline line ending), type M 120 120 500. Both wheels should turn forward for half a second. If one spins backward, swap that motor's two wires.
  2. Sensor. Type D with your hand at different distances. Readings should track a ruler within a few centimeters.
  3. Reflex. Hold your hand 10 cm in front and type M 120 120 2000: the reply must be ERR obstacle. Start a move, then put your hand in front: the wheels must stop and the board prints EVENT obstacle_stop.
  4. Serial from Python. On the Pi: pip install pyserial, then python -m serial.tools.miniterm /dev/ttyACM0 115200 and repeat steps 1–2.
  5. Calibrate. On the floor, run M 150 150 2000 and measure the distance: CM_PER_SEC = distance / 2. Do the same for turning with M -150 150 2000 to get DEG_PER_SEC. Put both numbers in robot_agent.py.
  6. Body + reflex brain. python robot_agent.py --port /dev/ttyACM0. The robot should wander and turn at walls.
  7. LLM brain. Only now: --brain claude or --brain ollama, in an open space, with your hand near the power switch.
Concept

9.6Which brain: Claude in the cloud or a model on the robot?

You asked for a robot that runs its own LLM. That works, with trade-offs. A Raspberry Pi has no large GPU, so it can run only small models, slowly. A cloud model like Claude is far more capable, but needs a network connection and adds a round trip to every decision.

A good design: hybrid

Keep everything time-critical on the robot (firmware reflexes, and maybe a local model for simple voice commands like "stop" or "come here"), and call Claude for open-ended planning ("find the red box"), sending it camera snapshots through a look() tool that returns an image. Tool results may contain images as well as text.

9.7Growing up: ROS 2 and bigger robots

Past a hobby robot, most research and industry robots use ROS 2, the Robot Operating System: a framework in which each part of the robot is a node (camera driver, lidar driver, mapper, planner, motor controller), exchanging typed messages on topics. Mature packages give you mapping (SLAM), localization and navigation (Nav2) with A*-family planners, the same search from lesson 03. An LLM agent then sits on top, with tools such as navigate_to(place) that send goals to the navigation stack.

Sketch: an agent tool that drives a ROS 2 robot (not run here: needs ROS 2)
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist

class LLMDriver(Node):
    def __init__(self):
        super().__init__("llm_driver")
        self.cmd = self.create_publisher(Twist, "cmd_vel", 10)   # the standard velocity topic

    def drive(self, speed_m_s: float, turn_rad_s: float) -> str:
        """Tool: set forward speed and turn rate. Clamped to safe limits."""
        msg = Twist()
        msg.linear.x = max(-0.2, min(0.2, speed_m_s))
        msg.angular.z = max(-1.0, min(1.0, turn_rad_s))
        self.cmd.publish(msg)
        return f"driving at {msg.linear.x} m/s, turning {msg.angular.z} rad/s"

rclpy.init()
node = LLMDriver()
print(node.drive(0.1, 0.0))

The research frontier goes further: vision-language-action models are trained to output robot actions directly from camera images and instructions. For your own projects, the layered design in this lesson (LLM plans, code validates, firmware reflexes protect) is the dependable path.

Safety

9.8Physical safety checklist

  • A physical power switch you can reach, and a habit of using it.
  • First tests with the wheels off the ground; first floor tests at low speed in an empty space.
  • Speed and distance limits in firmware (they are in robot_firmware.ino), not only in Python and never only in the prompt.
  • Motion that stops by itself: every command has a timeout, so a crashed program cannot leave the motors running.
  • Batteries: use a charger made for the chemistry; never leave lithium packs charging unattended; protect wires from shorts.
  • No unattended autonomous runs near people, pets or stairs (the HC-SR04 does not see drop-offs).
