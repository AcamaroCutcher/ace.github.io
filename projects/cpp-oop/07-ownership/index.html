Ownership, cloning, factories and RTTI

Polymorphic objects live behind pointers, so every design must answer: who owns this object, who may copy it, and who creates it? Smart pointers and a few idioms answer all three.

Smart pointers: saying who owns what

  • std::unique_ptr<T>: one owner. Cannot be copied, only moved. The default choice; with the default deleter it is the same size as a raw pointer and costs nothing extra to use.
  • std::shared_ptr<T>: shared ownership with a reference count; the object dies with its last owner. Use it when ownership is genuinely shared.
  • std::weak_ptr<T>: observes a shared_ptr's object without owning it; lock() gives a temporary owner if it still exists. It breaks ownership cycles such as parent ↔ child.
  • Raw pointers and references remain fine for non-owning access, such as function parameters.
smart_pointers.cppRun online ↗
// smart_pointers.cpp -- who owns a polymorphic object: unique_ptr, shared_ptr, weak_ptr
#include <iostream>
#include <memory>
#include <string>
#include <vector>

struct Node {
    std::string name;
    std::vector<std::shared_ptr<Node>> children;   // parents own their children
    std::weak_ptr<Node> parent;                    // children only observe their parent: no ownership cycle
    explicit Node(std::string n) : name(std::move(n)) { std::cout << "  + " << name << '\n'; }
    ~Node() { std::cout << "  - " << name << '\n'; }
};

struct Shape { virtual ~Shape() { std::cout << "  ~Shape\n"; } virtual const char* name() const = 0; };
struct Circle : Shape { ~Circle() override { std::cout << "  ~Circle\n"; } const char* name() const override { return "circle"; } };

std::unique_ptr<Shape> make_shape() { return std::make_unique<Circle>(); }   // a factory hands over ownership
void consume(std::unique_ptr<Shape> s) { std::cout << "  consume() now owns a " << s->name() << '\n'; }

int main() {
    std::cout << "unique_ptr: exactly one owner\n";
    auto s = make_shape();
    // auto copy = s;                        // error: unique_ptr cannot be copied
    consume(std::move(s));                   // ownership moves into the function, and dies with it
    std::cout << "  s is now " << (s ? "set" : "empty") << '\n';

    std::cout << "shared_ptr: shared ownership, counted\n";
    auto root = std::make_shared<Node>("root");
    {
        auto leaf = std::make_shared<Node>("leaf");
        leaf->parent = root;
        root->children.push_back(leaf);
        std::cout << "  leaf owners: " << leaf.use_count() << '\n';     // leaf + root's vector
        if (auto p = leaf->parent.lock()) std::cout << "  leaf's parent is " << p->name << '\n';
    }
    std::cout << "  root owners: " << root.use_count() << " (the weak_ptr does not count)\n";
    std::cout << "end of main\n";
}
Output

  ~Circle
  ~Shape
  s is now empty
shared_ptr: shared ownership, counted

Copying through a base pointer: virtual clone

Copy constructors are not virtual: given a Shape*, you cannot write Shape copy = *p without slicing. The clone idiom asks the object to copy itself. Here it uses a covariant return type: an override may return a pointer to the derived class (Circle*) where the base returns Shape*.

clone.cppRun online ↗
// clone.cpp -- copying objects you only know through a base pointer: the virtual clone idiom
#include <iostream>
#include <memory>
#include <vector>

class Shape {
public:
    virtual ~Shape() = default;
    virtual double area() const = 0;
    virtual void scale(double k) = 0;
    std::unique_ptr<Shape> clone() const { return std::unique_ptr<Shape>(do_clone()); }   // non-virtual wrapper
private:
    virtual Shape* do_clone() const = 0;          // each class copies itself, so the real type is kept
};

class Circle : public Shape {
public:
    explicit Circle(double r) : r_(r) {}
    double area() const override { return 3.14159 * r_ * r_; }
    void scale(double k) override { r_ *= k; }
private:
    Circle* do_clone() const override { return new Circle(*this); }   // covariant return type: Circle*, not Shape*
    double r_;
};

class Rect : public Shape {
public:
    Rect(double w, double h) : w_(w), h_(h) {}
    double area() const override { return w_ * h_; }
    void scale(double k) override { w_ *= k; h_ *= k; }
private:
    Rect* do_clone() const override { return new Rect(*this); }
    double w_, h_;
};

using Scene = std::vector<std::unique_ptr<Shape>>;

Scene deep_copy(const Scene& s) {                 // a vector of unique_ptr cannot be copied directly
    Scene out;
    for (const auto& p : s) out.push_back(p->clone());
    return out;
}

double total(const Scene& s) { double t = 0; for (const auto& p : s) t += p->area(); return t; }

int main() {
    Scene a;
    a.push_back(std::make_unique<Circle>(1));
    a.push_back(std::make_unique<Rect>(2, 3));
    Scene b = deep_copy(a);
    for (auto& p : b) p->scale(2);                // changing the copy...
    std::cout << "original total " << total(a) << '\n';   // ...leaves the original alone
    std::cout << "scaled copy total " << total(b) << '\n';
}
Output
original total 9.14159
scaled copy total 36.5664

Factories: creating objects from data

Constructors are not virtual either: to create an object whose type is only known at run time (from an input file, a menu, a network message) use a factory. A registry maps names to creation functions; adding a new shape means one new line in the table, and the reading code never changes:

factory.cppRun online ↗
// factory.cpp -- creating objects from text, e.g. an input file, through a registry of constructors
#include <functional>
#include <iostream>
#include <map>
#include <memory>
#include <sstream>
#include <stdexcept>
#include <string>
#include <vector>

struct Shape {
    virtual ~Shape() = default;
    virtual double area() const = 0;
    virtual std::string describe() const = 0;
};
struct Circle : Shape {
    double r;
    explicit Circle(std::istream& in) { if (!(in >> r)) throw std::runtime_error("circle needs a radius"); }
    double area() const override { return 3.14159 * r * r; }
    std::string describe() const override { std::ostringstream s; s << "circle r=" << r; return s.str(); }
};
struct Rect : Shape {
    double w, h;
    explicit Rect(std::istream& in) { if (!(in >> w >> h)) throw std::runtime_error("rect needs width and height"); }
    double area() const override { return w * h; }
    std::string describe() const override { std::ostringstream s; s << "rect " << w << "x" << h; return s.str(); }
};

using Maker = std::function<std::unique_ptr<Shape>(std::istream&)>;

std::map<std::string, Maker>& registry() {         // name -> how to build it
    static std::map<std::string, Maker> r = {
        {"circle", [](std::istream& in) { return std::make_unique<Circle>(in); }},
        {"rect",   [](std::istream& in) { return std::make_unique<Rect>(in); }},
    };
    return r;
}

std::unique_ptr<Shape> make(const std::string& line) {
    std::istringstream in(line);
    std::string kind;
    in >> kind;
    auto it = registry().find(kind);
    if (it == registry().end()) throw std::runtime_error("unknown shape '" + kind + "'");
    return it->second(in);
}

int main() {
    const char* input = "circle 1\nrect 2 3\nhexagon 1\nrect 4\ncircle 0.5\n";   // pretend this is a file
    std::istringstream file(input);
    std::vector<std::unique_ptr<Shape>> shapes;
    std::string line;
    int n = 0;
    while (std::getline(file, line)) {
        ++n;
        try { shapes.push_back(make(line)); }
        catch (const std::exception& e) { std::cout << "line " << n << ": " << e.what() << '\n'; }
    }
    for (const auto& s : shapes) std::cout << s->describe() << " -> area " << s->area() << '\n';
}
Output
line 3: unknown shape 'hexagon'
line 4: rect needs width and height
circle r=1 -> area 3.14159
rect 2x3 -> area 6
circle r=0.5 -> area 0.785397

RTTI: dynamic_cast and typeid

Run-time type information lets code ask what an object really is. dynamic_cast<T*> returns nullptr if the object is not a T (or derived from it); the reference form throws std::bad_cast; typeid compares exact types.

rtti.cppRun online ↗
// rtti.cpp -- asking an object what it really is: dynamic_cast and typeid
#include <iostream>
#include <memory>
#include <typeinfo>
#include <vector>

struct Shape { virtual ~Shape() = default; };
struct Circle : Shape { double r = 1; };
struct Rect : Shape { double w = 2, h = 3; };
struct Square : Rect {};

int main() {
    std::vector<std::unique_ptr<Shape>> v;
    v.push_back(std::make_unique<Circle>());
    v.push_back(std::make_unique<Rect>());
    v.push_back(std::make_unique<Square>());

    for (const auto& p : v) {
        // dynamic_cast to a pointer: nullptr when the object is not of that type (or derived from it)
        if (auto r = dynamic_cast<const Rect*>(p.get()))
            std::cout << "a Rect (or derived) with area " << r->w * r->h;
        else
            std::cout << "not a Rect";
        // typeid compares exact dynamic types
        const Shape& ref = *p;
        std::cout << (typeid(ref) == typeid(Square) ? ", exactly a Square" : "") << '\n';
    }

    // dynamic_cast to a reference cannot return nullptr, so it throws
    try {
        Shape& s = *v[0];
        Rect& r = dynamic_cast<Rect&>(s);
        std::cout << r.w << '\n';
    } catch (const std::bad_cast&) {
        std::cout << "bad_cast: the first shape is not a Rect\n";
    }
}
Output
not a Rect
a Rect (or derived) with area 6
a Rect (or derived) with area 6, exactly a Square
bad_cast: the first shape is not a Rect

A design smell A chain of if (dynamic_cast<A*>) … else if (dynamic_cast<B*>) … usually means a virtual function is missing: let each class do its own thing. Use dynamic_cast for optional capabilities (as with interfaces in lesson 06), not as a switch over types. If you really need a switch over a fixed set of types, see std::variant in the next lesson.

Key points

  • Own polymorphic objects with std::unique_ptr<Base>; share only when needed; observe with raw pointers or weak_ptr.
  • Copy through a base with a virtual clone(); create from data with a factory.
  • Prefer virtual functions to dynamic_cast chains.
