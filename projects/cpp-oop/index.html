Before you start

Object-oriented programming organizes a program around objects: bundles of data together with the operations allowed on that data. C++ supports it with four tools, and the lessons take them in order:

  • Encapsulation (lessons 01–03): a class hides its data behind functions that keep it valid, and controls how it is created, copied and destroyed.
  • Inheritance (04): a new class is built from an existing one and is usable wherever the old one is expected.
  • Polymorphism (05, 07, 08): one call, shape.area(), runs different code depending on the actual object.
  • Abstraction (06, 09): an abstract class states what every derived class must do, without saying how.

You need a C++17 compiler (one example uses C++20). Save any program and compile it with warnings on, or press Run online on a program to edit and run it in your browser with GCC on Compiler Explorer:

terminal
g++ -std=c++17 -Wall -Wextra -g classes.cpp -o classes     # or clang++ instead of g++
./classes
