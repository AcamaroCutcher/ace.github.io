Memory or no memory?

The report gives two answers for a Cascadia M9 in the next 50 years: 10% if earthquakes have no memory, and 15% if the fault "remembers" that its last great quake was on January 26, 1700 (p. 4). The difference comes down to one question: does waiting make a quake more likely?

No memory (Poisson)

Like rolling a die every year

The chance is the same every year, whether the last quake was yesterday or 300 years ago. With one M9 every ~500 years on average, that's a 0.2% chance each year.

Memory (Brownian passage time)

Like a spring being loaded

Strain builds up after each rupture, so a new great quake is very unlikely right after the last one and becomes more likely as time passes. 326 years have passed since 1700.

Southern Cascadia: ~30% in 50 years

In the south, partial ruptures (M~8) add to full-margin M9s, giving one great quake every ~300–350 years (Figure 4 uses 330). The report's ~30% is a memory model. It adds that it is "not entirely clear how to apply a time-dependent rupture model in a region of the subduction zone that may host a range of earthquake magnitudes" (p. 4). Memory raises today's odds

Because 326 years have already passed, a memory model puts the next 50 years at ~14–15% instead of 10%. Right after 1700, the same model would have said almost 0%.

Neither model predicts a date

Even with memory, 85% of the time the next 50 years pass without an M9. The gaps between past great quakes ranged from a few centuries to about a thousand years.

The settings are uncertain

The average gap and the regularity come from geological records with large error bars. That's why the report gives a range, 10–15%, rather than one number.
