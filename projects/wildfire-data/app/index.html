Moving around the map

Mouse

  • Drag: move the map
  • Right-drag or Ctrl + drag: rotate and tilt
  • Scroll: zoom toward the pointer
  • Double-click: zoom in there

Touch

  • One finger: move
  • Pinch: zoom
  • Two-finger twist: rotate
  • Two-finger drag up/down: tilt

Keyboard

  • ←→↑↓ move · +− zoom
  • QE rotate · RF tilt
  • T map view · V 3D · N north · O orbit · Home frame fire
  • Space play · ,. previous / next pass · H this help

About the fire front: satellites see a fire only a few times a day, so the front between passes is reconstructed: each spot is timed by its distance from where the fire was at the previous pass, so it arrives exactly when the next pass saw it. Mapped perimeters set hard limits. It is an interpolation of real observations, not a physics simulation. Links can open at a moment and view: ?fire=beachie-creek-2020&t=2020-09-08T07:00Z.
